Windows 10/11 x64 portable edition
Extract the complete folder, then double-click HalfFrame.cmd. Python installation is not required.
Keep the launchers, app, and runtime together when moving this folder.
If startup fails, run HalfFrame-debug.cmd to see the error message.
Bilingual instructions, changelog, and the MIT application license are in app.
Third-party components retain their own licenses; see app/THIRD_PARTY_NOTICES.md.
